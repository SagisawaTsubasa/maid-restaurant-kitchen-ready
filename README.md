# 女仆餐厅：烹饪兼容（maid-restaurant-cooking-compat）

女仆餐厅本体（maid_restaurant）的附属模组：把整合包全部烹饪/酿造配方类型接入「女仆厨师可做」体系——经本体 `CookTasks.register` 通用注册口注册各配方类型的烹饪任务适配器，营业 fork（maid-restaurant-business）的经营链按配方类型自动消费。

- 依赖：maid_restaurant 0.2.9（必需）；森罗厨房等宿主 mod（运行时软依赖）。
- 与营业 fork 关系：无依赖、无环，三者并存；营业链自动消费本模组注册的任务类型。
- 目标：配方扫描审计基线 3576 条 / 85 类全量兼容（本体原生覆盖约 723 条 / 20%）。
