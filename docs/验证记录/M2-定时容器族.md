## 公共骨架

`AbstractTimedContainerCookTask<R>`（T3 基类）：盒扫寻块+占用过滤、getAllRecipeData 统一出口（排除过滤器）、byKey+instanceof 解析、getType=recipeType()。泛型注记：NeoForge 1.21.1 `RecipeManager.getAllRecipesFor` 签名 `<I extends RecipeInput, T extends Recipe<I>>`（javap 实测），`R extends Recipe<?>` 推断不过 → raw 调用收窄。

## 真机抽验操作单（待人工）

每类抽 2-3 例，通用步骤：放置工作方块→女仆下单→观察「取料→投料→等待→取货→上菜」全链：

1. 竹匾：屋顶外放匾，下单一道晾晒（如湿竹笋→干竹笋）；雨天测淋湿侧。
2. 茶壶：热源上方留空位（女仆应自动补放茶壶），下单任一茶饮；确认茶壶循环（第一壶后不卡单）。
3. 腌菜罐：下单皮蛋类；确认女仆投料后自动关盖、完成后取货。
4. 冰箱（国味/烟火）+ 醒发箱 + 筒仓 + 冰柜 + 煮茶壶：各一单。
