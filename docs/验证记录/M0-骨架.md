## 过程坑与修法（实测复现）

1. **javac Plugin service 炸启动**：libs 中「创建宇航学cosmonautics-26.08.307.jar」携带 `META-INF/services/com.sun.source.util.Plugin` → `dev.devce.rocketnautics.shaded.orekit.compiler.plugin.DefaultDataContextPlugin`（类缺失）。javac 启动对 **classpath** 做 Plugin ServiceLoader 扫描即炸（`javac -cp 该jar` 最小复现 100%）；`options.annotationProcessorPath=files()` 与 `fork=true` 均绕不开。修法：`compileOnly fileTree(exclude: '创建宇航学*')`——该 mod 8 条配方全是原版烧炼/高炉（M3 数据驱动路由），无需编译期类型。
2. **PowerShell Copy-Item 方括号通配坑**：客户端 jar 名带 `[]`（如 `[烘焙坊] bakeries-…jar`）时 Copy-Item 把目标路径方括号当通配符，37 个文件静默未落盘。修法：`[System.IO.File]::Copy` 字面复制。
3. **PS1 中文编码坑**：PS5.1 读无 BOM UTF-8 脚本按 ANSI，中文字面量损坏。修法：脚本 ASCII-only（中文名一律运行时探测）。
4. gradle.properties 中文坑沿先例规避（中文只进 toml 模板）。
