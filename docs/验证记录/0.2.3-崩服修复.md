## 根因（一句话）

本体 `MaidStateManager.cookState`（0.2.9 all.java:8713）对 `ICookTask.getIngredients` 返回值**原地 addAll**(kitchenWares)，本包全部实现以 `Stream.toList()`/`List.of()` 收尾（不可变）→ 女仆 AI 启动「走近厨具做饭」检查时 `ImmutableCollections.addAll` 无条件抛 UOE → Ticking entity 崩服；CookRequest 持久化 → 不换 jar 复崩。
