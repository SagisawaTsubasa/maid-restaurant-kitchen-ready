2. 牛奶桶→空桶容器返还：空桶回包不掉地；
3. 缺料 rollback：原料回包不掉地；
4. 满背包交付：溢出掉地 + WARN「女仆背包已满，交付溢出掉地」；
5. 茶壶取茶（takeTeapot）：茶成品+茶壶均在女仆包，不在主手；
6. 竹匾取货（onTakeOut）：成品在女仆包，不在主手；
7. flex 炒锅/汤锅取菜（takeOutProduct）：成品+铲/carrier 在女仆包，不在主手；
8. 汤锅投汤底（addSoupBase）：空桶返还回包不掉地；WATER 汤底同路径（真扣减 1 桶水+空桶回包，无水凭空生成/空桶消失）；
