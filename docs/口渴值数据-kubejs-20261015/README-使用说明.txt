口渴值数据同步包（2026-10-15）
====================================

这是什么：
服务器 LSO（传说生存）口渴值登记数据的完整副本，共 643 个 JSON、44 个模组命名空间。
与服务器 `/reload` 后的口渴表一致（LSO 计数 825，含 LSO 内嵌数据）。
含 10-07 全量补齐 + 10-12 两次追补（酒馆音译酒 28 项、世界名酒/次元酒窖 66 项）。

怎么装：
把本文件夹里的 `kubejs` 整个文件夹复制/合并到客户端整合包根目录
（与 mods、config 同级）。已有同名文件直接覆盖即可——同名=同值，合并无风险。
不需要删除客户端里已有的其他 kubejs 文件。

装完要不要重启：
- 进服务器：不需要。LSO 进服时会由服务器整表同步口渴数据，悬停提示自动生效。
  本包的作用是让客户端本地数据与服务器设计对齐（单机测试/一致性）。
- 单机测试：需要重进一次世界让数据加载。
